# 정보보안기사 핵심정리

정보보안기사 시험범위를 공식 출제기준 기준으로 정리한 한글 학습 노트입니다.  
확인일: 2026-05-03

## 공식 기준

- 시행기관: 한국방송통신전파진흥원(KCA)
- 적용 출제기준: 2023.1.1. ~ 2026.12.31.
- 필기: 객관식 4지선다형, 100문항, 2시간 30분
- 필기 과목: 시스템보안, 네트워크보안, 어플리케이션보안, 정보보안일반, 정보보안관리 및 법규
- 필기 합격: 과목당 40점 이상, 전 과목 평균 60점 이상
- 실기: 정보보안 실무, 필답형, 3시간
- 실기 합격: 100점 만점 60점 이상

```bash
python3 scripts/check_markdown.py
```

같은 검사는 pull request와 `main` 브랜치 push 때 GitHub Actions에서도 자동으로 실행됩니다.

## 공부 방향

1. `00-시험범위-출제기준.md`로 시험이 묻는 큰 범위를 먼저 확인합니다.
2. 처음 공부할 때는 `15-합격권-해설형-통합이론서.md`를 중심으로 읽으며 키워드의 의미와 출제 방식을 이해합니다.
3. 필기를 먼저 준비한다면 `24-필기-우선합격-전략.md`로 과목별 과락 방지선을 잡고, 과목별 파일을 1회독한 뒤 `25-필기-객관식-60제.md`와 `29-필기-추가객관식-100제.md`를 풉니다.
4. 암호학은 `04-정보보안일반.md`로 전체 흐름을 잡고 `09-암호학-심화-그림정리.md`의 그림자료와 비교표를 반복합니다.
5. 범위를 더 촘촘히 보려면 `11-전과목-심화-키워드맵.md`와 `12-공격-취약점-대응-매트릭스.md`를 봅니다.
6. 필기 객관식에서 자주 흔들리는 선택지는 `26-필기-선택지-함정노트.md`로 정리하고, 시험 직전에는 `10-빈출-그림요약.md`로 과목별 흐름도를 빠르게 회독합니다.
7. 필기 점수를 안정적으로 올리려면 `27-필기-약점진단.md`로 약점을 분류하고, `28-필기-빈출개념-200포인트.md`, `30-필기-오답회독-7일플랜.md`, `31-필기-암호네트워크-집중특훈.md`을 반복합니다.
8. 네트워크보안 점수를 끌어올릴 때는 `32-네트워크보안-필기집중정리.md`로 계층과 공격 단서를 잡고, `33-네트워크보안-객관식-80제.md`와 `34-네트워크보안-패킷로그-그림훈련.md`을 반복합니다.
9. 실기는 `06-실기-정보보안실무.md`의 답안 틀을 외운 뒤 `13-실기-필답형-답안사례.md`와 `16-해설형-문제풀이-훈련.md`처럼 직접 문장으로 써보는 방식으로 연습합니다.
10. 선택지에서 자주 헷갈리는 개념은 `17-헷갈리는-개념-완전정리.md`로 비교해서 정리합니다.
11. 시험 1주 전에는 `18-최종암기장-120문답.md`와 `19-최종모의고사-1회.md`로 약점을 찾고 `20-오답노트-약점추적-템플릿.md`에 틀린 이유를 기록합니다.
12. 실기 점수를 올리려면 `21-실기-로그패킷-분석-워크북.md`로 로그 근거를 찾아 답안화하고, `22-보안설정-점검-체크리스트.md`로 점검형 답안 문장을 반복합니다.
13. 법규는 개정 가능성이 높으므로 `14-법규-관리-최신체크.md`와 `23-법규-상황형-판단문제.md`를 기준으로 시험 직전 KCA 공지와 국가법령정보센터에서 현행 조문을 다시 확인합니다.
