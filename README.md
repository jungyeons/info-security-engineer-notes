# 정보보안기사 핵심정리

정보보안기사 시험범위를 공식 출제기준 기준으로 정리한 한글 학습 노트입니다.  
확인일: 2026-05-03

## 공식 기준

- 시행기관: 한국방송통신전파진흥원(KCA)
- 적용 출제기준: 2023.1.1. ~ 2026.12.31.
- 필기: 객관식 4지선다형, 100문항, 2시간 30분
- 필기 과목: 시스템보안, 네트워크보안, 어플리케이션보안, 정보보안일반, 정보보안관리 및 법규
- 필기 합격: 과목당 40점 이상, 전 과목 평균 60점 이상
- 실기: 정보보안 실무, 필답형, 3시간
- 실기 합격: 100점 만점 60점 이상

## 공부 방향

1. `00-시험범위-출제기준.md`로 시험이 묻는 큰 범위를 먼저 확인합니다.
2. 필기는 과목별 파일을 1회독한 뒤 `07-암기표-체크리스트.md`로 반복합니다.
3. 암호학은 `04-정보보안일반.md`로 전체 흐름을 잡고 `09-암호학-심화-그림정리.md`의 그림자료와 비교표를 반복합니다.
4. 시험 직전에는 `10-빈출-그림요약.md`로 과목별 흐름도를 빠르게 회독합니다.
5. 실기는 `06-실기-정보보안실무.md`의 답안 틀을 외운 뒤, 로그/설정/취약점 사례를 직접 써보는 방식으로 연습합니다.
6. 법규는 개정 가능성이 높으므로 시험 직전 KCA 공지와 국가법령정보센터에서 현행 조문을 다시 확인합니다.
